# content

Тексты проекта: актуализированная статья, тексты блоков лонгрида, сценарии видео и подкаста, подписи, вопросы для игры или бота.

## Правила

- Каждое фактическое утверждение сопровождается ссылкой на источник из выданного набора (`S01`–`S18`) и, если есть, на ID факта из книги (`F001…`).
- Текст передаётся фактчекеру до публикации на лендинге.
- Версия, прошедшая проверку, помечается датой проверки.
- Художественные и оценочные фрагменты отделяются от фактических так, чтобы читатель видел границу.
