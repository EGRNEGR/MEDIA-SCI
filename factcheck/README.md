# factcheck

Результаты фактчекинга проекта: аудит, реестр утверждений, реестр источников, отчёты и список исправлений.

Работа ведётся в ветке `FactsCheck`. В `main` этот каталог пуст до тех пор, пока команда не решит перенести результаты проверки.

## Правила

- Одно утверждение — одна строка реестра с уникальным ID.
- У каждого вывода есть статус, приоритет, источник и точное указание на место доказательства.
- Статусы и приоритеты описаны в [`docs/workflow/editorial_standards.md`](../docs/workflow/editorial_standards.md).
- Если подтверждение найти не удалось, это записывается прямо. Источники, цитаты и ссылки не придумываются.
