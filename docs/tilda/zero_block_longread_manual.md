# «Несуществующий гардероб»: сборка лонгрида в Zero Block на тарифе Tilda Free

Мануал для команды. Цель — за один вечер собрать иммерсивный лонгрид по статье РУВИКИ «Виртуальная одежда» без блока T123, без своего CSS и JS, только штатными средствами Zero Block. Все тексты взяты из финальной версии статьи (файл «Финальный аудит статьи «Виртуальная одежда».docx»), номера в квадратных скобках совпадают с примечаниями статьи — список в разделе 9.

Готовые материалы лежат в этом репозитории:

| Что | Путь | Где используется |
|---|---|---|
| 12 кадров турникета 960×1200, JPEG, фон `#0B0D10` | `media/3d/turntable/turntable_00.jpg` … `turntable_11.jpg` | ZB01, ZB03 |
| Анимированный GIF 400×500, 48 кадров | `media/3d/loop/iridescence_turntable.gif` | ZB01, мобильная версия ZB03 |
| 6 полос кадра 0 для «перекрута» | `media/3d/twist/twist_strip_1.jpg` … `_6.jpg` | ZB08 |
| Шкала и стрелка «компаса» 240×240, PNG с прозрачностью | `media/3d/hud/dial_ring.png`, `dial_needle.png` | ZB03 |
| 3D-сцена на Three.js для GitHub Pages | `media/3d/iridescence-viewer/index.html` | ссылка и QR из ZB01, ZB07, ZB11 |

Платье на всех кадрах — условная реконструкция, построенная в нашем Three.js-скрипте. Это не модель The Fabricant, и на странице это нужно подписать (раздел 7).

## Собранная версия (13.11.2026)

Лонгрид собран по этому мануалу и опубликован: **https://wholly-champion-grunt.tilda.ws/wardrobe** (аккаунт Egor, проект GaugeVision AI, страница `pageid=383346509`, тариф Free). Одиннадцать Zero Block сгенерированы скриптом `tools/tilda_zero/build_blocks.py`: он описывает слои, адаптив и анимацию в формате редактора и сохраняет JSON в `tools/tilda_zero/out/`. Чтобы пересобрать блок после правки текста:

1. `python tools/tilda_zero/build_blocks.py ZB05` — пересобрать нужные блоки.
2. Закоммитить и запушить `tools/tilda_zero/out/`.
3. В открытом редакторе страницы Tilda отправить JSON на `/zero/submit/` (`comm=savezerocode`, `onlythisfield=code`) — так же, как это делает кнопка «Сохранить» в Zero Block. Потом «Опубликовать».

Что выяснилось при сборке и уже учтено в рецептах ниже:

- **Move, Rotate и Scale в пошаговой анимации считаются от нулевого шага, а не от позиции элемента.** Если первый шаг задаёт позу (поворот, сдвиг), элемент в конце окажется смещён на минус эту позу. Первым шагом всегда ставим нейтральный (все сдвиги 0, Scale 100), а стартовую позу — вторым шагом с длительностью 0.
- **Событие On Click не применяет стартовый шаг до клика.** Элемент с Opacity 0 в первом шаге всё равно виден. Рабочий приём: положить скрытый слой за край артборда (X + 2000, артборд с Overflow: Hidden его обрезает), а клик мгновенно возвращает его на место (Move X −2000, длительность 0) и проявляет. Loop — «Проиграть один раз», иначе второй клик проигрывает анимацию назад.
- Trigger Offset = Y слоя при Start Trigger «On Window Top» синхронизирует всю сцену — проверено на турникете и ленте.
- Моноширинных шрифтов в библиотеке Free нет: телеметрия набрана TildaSans прописными с разрядкой 1.2.
- Мобильные брейкпоинты (640 и меньше) включены с автомасштабом (Autoscale: Window), десктоп и 960 — по сетке, чтобы не сбивались пиксельные сцены.
- Отличия от плана: в ZB06 вместо одометра — крупные числа с Zoom In (шторки одометра перекрывали соседние слои), три эпохи собраны в одном блоке ZB05 тремя колонками вместо вкладок.

## 0. Что точно работает на Free и что проверить

Проверено по справке Tilda 13.11.2026.

| Возможность | Статус на Free | Источник |
|---|---|---|
| Zero Block | Доступен | справка и обзоры тарифа |
| Блоки T123 и T868 (свой HTML) | **Отключены** | [tilda.cc/ru/answers/a/freeplan](https://tilda.cc/ru/answers/a/freeplan/) |
| Базовая анимация: Fade In, Zoom In, Parallax (Scroll, Mouse), Fixing | Есть в Zero Block | [help-ru.tilda.cc/zero/animation](https://help-ru.tilda.cc/zero/animation) |
| Пошаговая анимация (STEP BY STEP, BETA): события Element on Screen, Block on Screen, On Scroll, On Hover, On Click; поля шага Duration, Move, Scale, Opacity, Rotate, Easing, Delay | Есть в Zero Block, ограничений по тарифу в справке нет | [help-ru.tilda.cc/zero/advanced-animation](https://help-ru.tilda.cc/zero/advanced-animation) |
| Триггер: клик или наведение на один элемент запускает анимацию другого (Add Trigger) | Есть | [tilda.cc/lp/trigger-animation](https://tilda.cc/lp/trigger-animation/) |
| Сбор данных из форм | **Не работает** — опросы с подсчётом голосов не делаем | справка о Free |
| HTML-элемент внутри Zero Block | **Не подтверждено**: источники противоречат друг другу | см. раздел 6 |

Три правила, на которых держится весь мануал:

1. **При событии On Scroll длительность шага измеряется в пикселях прокрутки, а не в секундах.** Шаг с Duration 300 проигрывается за 300 px скролла и откатывается назад при обратном скролле.
2. **Move в каждом шаге — накопительное смещение, отсчитанное от нулевого (первого) шага, а не от предыдущего.** Поэтому в таблицах ниже значения Move накопительные, а первый шаг везде нейтральный: все сдвиги и поворот 0, Scale 100.
3. **Пошаговая анимация отменяет базовую на том же элементе.** Fixing и Step-by-Step на одном слое не совмещаются. Если слою нужны и «залипание», и движение, залипание имитируем компенсацией (рецепт R3).

## 1. Фаза 1. Сетка, палитра, типографика

### 1.1. Настройки сайта и страницы

1. **Настройки сайта → Шрифты и цвета.** Основной шрифт — Manrope или Inter, если их нет в списке — TildaSans. Цвет текста `#F4F6F9`, фон страницы `#0B0D10`.
2. **Настройки страницы → Фон** — `#0B0D10`. Без этого между Zero Block на широких экранах мелькают белые полосы.
3. Моноширинный шрифт для индексов и телеметрии выбирайте в списке шрифтов текстового элемента: JetBrains Mono, IBM Plex Mono или Roboto Mono — что есть в библиотеке.

### 1.2. Настройки артборда (одинаковые для всех Zero Block)

Открыть блок → **Edit Block** → клик по пустому месту артборда → панель справа.

| Параметр | Значение |
|---|---|
| Grid container width | 1200 |
| Columns / Gutter / Margin | 12 / 40 / 20 |
| Background color | `#0B0D10` |
| Height | указан в паспорте каждого блока |
| Overflow | Hidden (иначе кадры R4 и ленты R5 вылезают за блок) |

Брейкпоинты Zero Block: 1200, 960, 640, 480, 320. Все координаты ниже даны для **1200**. Для 960 сдвиньте правый край контента на 240 px влево или пропорционально ужмите, а для 640 и меньше используйте мобильные дубликаты (раздел 1.6).

Все элементы, если не сказано иное: **Container — Grid Container, Axis X — Left, Axis Y — Top**. Координаты X и Y отсчитываются от левого верхнего угла грид-контейнера.

### 1.6. Мобильная стратегия

Скролл-сцены R3–R5 со сдвигами в сотни пикселей не переносятся на 320–480 px. Поэтому:

- сложные слои показываются только на 1200 и 960. На 640, 480 и 320 скройте их иконкой глаза в панели слоя;
- рядом кладутся **мобильные дубликаты** с суффиксом `_m`: обычная вертикальная вёрстка с базовой анимацией Fade In Up. Дубликаты скрыты на 1200 и 960;
- высоту артборда на мобильных брейкпоинтах задайте отдельно (панель артборда на выбранном брейкпоинте).

## 2. Фаза 2. Механики скролла без кода: рецепты

Каждый рецепт — набор полей панели **STEP BY STEP ANIMATION** (кнопка ADD в настройках элемента). Обозначения: `Dur` — Duration (при On Scroll — пиксели скролла), `Op` — Opacity, `Sc` — Scale, `Rot` — Rotate, `MvX` / `MvY` — Move по осям, `Ease` — Easing.

Как задать стартовое состояние: справка Tilda советует **первый шаг с Duration 0** — например, Op 0, чтобы элемент стартовал скрытым. В таблицах это «Шаг 1».

### R1. Появление с «перекрутом» (карточки, заголовки)

Карточка влетает развёрнутой и уменьшенной, затем выпрямляется. Событие **Element on Screen**, Start Trigger **On Window Bottom**, Trigger Offset **120**.

| Шаг | Dur | Op | Sc | Rot | MvX | MvY | Ease | Delay |
|---|---|---|---|---|---|---|---|---|
| 1 (нейтральный) | 0 | 0 | 100 | 0 | 0 | 0 | — | 0 |
| 2 (поза) | 0 | 0 | 86 | −12 | 140 | 120 | — | 0 |
| 3 | 0.9 | 100 | 100 | 0 | 0 | 0 | easeOut | 0 / 0.12 / 0.24 |

Для веера из трёх карточек поменяйте знаки: левая — Rot −12, MvX 140; центральная — Rot 0, MvX 0, MvY 160; правая — Rot 12, MvX −140. Delay растёт слева направо.

### R2. Многослойный параллакс (глубина без 3D)

Три слоя с разной скоростью, **базовая анимация → Parallax → Scroll**:

| Слой | Что | Speed |
|---|---|---|
| Дальний | огромные контурные надписи `3D`, `AR`, `2D` (240 px, цвет `#12151B`) | 70 % |
| Средний | карточки (у них R1 — им параллакс не назначаем) | — |
| Ближний | пины, линии-выноски, телеметрия | 125 % |

Медленный дальний и быстрый ближний слой дают ощущение объёма вокруг неподвижных карточек. Для героя добавьте **Parallax → Mouse movement**, Distance X 20, Y 12 — картинка будет следовать за курсором.

### R3. «Залипание» сцены (pin) двумя способами

Сцена должна стоять на месте, пока пользователь прокручивает P пикселей. Высота артборда = 800 + P.

**Способ А — базовая Fixing** (для слоёв без пошаговой анимации): Fixing **On Window Top**, Trigger Offset **= Y элемента**, Distance **= P**.

**Способ Б — компенсация в пошаговой анимации** (для слоёв, которые одновременно меняют прозрачность, поворот или сдвиг): событие **On Scroll**, Start Trigger **On Window Top**, Trigger Offset **= Y элемента**, и в каждом шаге **MvY = пройденные пиксели скролла** при Ease **Linear**. Элемент едет вниз ровно с той скоростью, с какой страница уходит вверх, и визуально стоит на месте.

> Почему Trigger Offset = Y. Отсчёт идёт от выбранной линии окна, и элемент включается, когда доходит до неё со своим смещением (официальный урок Tilda «Фиксация текста при скролле»). Если каждому слою дать смещение, равное его Y, все слои «залипнут» в один момент — когда верх блока коснётся верха окна — и сохранят взаимное расположение. Проверьте одну сцену в предпросмотре: если слой прыгает на величину своего Y, поменяйте знак смещения у всех слоёв сцены.

### R4. Турникет 360° из 12 кадров (главный WOW-эффект)

Двенадцать кадров платья лежат стопкой в одной точке. Каждый следующий кадр выше предыдущего по слоям и включается чуть позже. Кадры непрозрачные (фон `#0B0D10` запечён), поэтому прятать старые не нужно: новый просто закрывает старый. Скролл назад откатывает анимацию сам.

Параметры: шаг поворота **D = 150 px** на кадр, P = 1800 px (1650 на оборот и 150 на паузу в конце). Все кадры: X 360, Y 100, W 480, H 600, событие On Scroll, Start Trigger On Window Top, Trigger Offset 100, Ease Linear.

### R5. Горизонтальная лента на вертикальном скролле

Сцена залипает (R3), а лента карточек уезжает влево. Ширина ленты: 12 карточек по 340 px с шагом 380 = 4520 px. Видимая область — 1160 px, поэтому сдвиг = 4520 − 1160 = **3360 px** за **P = 2400 px** скролла. Лента идёт в 1,4 раза быстрее скролла, это ощущается как «перемотка».

Каждый слой ленты (подложка и текст карточки, маркеры шкалы): событие On Scroll, Start Trigger On Window Top, Trigger Offset = Y слоя.

| Шаг | Dur | MvX | MvY | Ease |
|---|---|---|---|---|
| 1 | 2400 | −3360 | 2400 | Linear |

Числа одинаковы для всех слоёв ленты. Настройте первую карточку, потом дублируйте: копии сохраняют анимацию, меняются только X и текст. Если панель анимации активна у группы (Ctrl+G), назначьте шаги группе — так быстрее. Если неактивна, работайте поэлементно.

### R6. «Перекрут ткани» из полос

Кадр платья разрезан на 6 горизонтальных полос (`twist_strip_1…6.jpg`, каждая 960×200, на странице 480×100). При входе блока в экран полосы скручены и разъехались, на 500 px скролла они собираются в целое платье. Это образ: цифровая вещь собирается из данных.

Полосы: X 60, Y = 160 + 100·(n − 1), W 480, H 100. Событие On Scroll, Start Trigger On Window Bottom, Trigger Offset 0.

| 2 | Rot 12, MvX 80, Op 40 | Rot 0, MvX 0, Op 100 |
| 3 | Rot −9, MvX −40, Op 40 | Rot 0, MvX 0, Op 100 |
| 4 | Rot 9, MvX 40, Op 40 | Rot 0, MvX 0, Op 100 |

### R7. Одометр-счётчик без кода

## 4. Фаза 4. Хакатон-хуки

### 4.1. Квиз «Миф или факт?» (ZB10)

Собран на R8: клик по кнопке раскрывает вердикт с источником. Подсчёт баллов и сбор ответов без кода невозможны: формы на Free данные не принимают. Поэтому на странице честно написано, что ответы не сохраняются.

### 4.2. Переключатель эпох (ZB05a–c)

Внутри одного Zero Block настоящие вкладки без кода не собрать. Одному элементу назначается одна анимация, а схема «показать А и одновременно скрыть Б» требует двух. Все готовые решения «табов для Zero Block» — модификации, которые вставляются через T123, а на Free он отключён. Рабочие варианты:

1. **Штатный блок вкладок.** Откройте библиотеку блоков и введите в поиск «Вкладки» или «Табы». Если блок доступен на Free (в библиотеке нет замка), укажите в нём ID трёх блоков ZB05a–c — он сам будет показывать нужный. Проверьте после публикации.
2. **Якорные вкладки (работают всегда).** В каждом из трёх блоков есть панель из трёх кнопок со ссылками `#rec…` на ZB05a, b и c. Текущая вкладка подсвечена. Клик плавно прокручивает к нужной эпохе, а R1 на заголовке даёт эффект смены экрана.

### 4.3. Турникет по скроллу (ZB03)

Это главный эффект для жюри: платье делает полный оборот под пальцем или колесом мыши, стрелка-компас показывает угол, факты всплывают по ходу оборота. В питче на защите покажите его вживую — это 10 секунд.

### 4.4. 3D-сцена за пределами Tilda

Живая сцена с вращением мышью лежит на GitHub Pages (раздел 6). С лонгрида на неё ведут кнопки в ZB01, ZB07 и ZB11. На защите её можно открыть на телефоне жюри через QR-код: сгенерируйте QR на ссылку и вставьте картинкой в ZB11.

### 4.5. Наведение и мелкая телеметрия

R9 на карточках, моно-подписи `ROT`, `FRAME`, `STATUS`. Это декор, его не делаем раньше MVP.

## 6. 3D-сцена на Three.js: публикация за 2 минуты

Файл `media/3d/iridescence-viewer/index.html` самодостаточен: Three.js 0.170 подключается с CDN jsDelivr, сборка не нужна. Сцена: переливающееся платье (MeshPhysicalMaterial с iridescence), складки и покачивание подола, кольцо сканирования, шкала турникета, частицы, HUD с углом поворота. Управление: перетаскивание — поворот, колесо — масштаб. При `prefers-reduced-motion` автоповорот выключается.

**Публикация через GitHub Pages (отдельный репозиторий, самый быстрый путь):**

1. github.com → New repository → имя `iridescence-3d`, Public → Create.
2. «uploading an existing file» → перетащить `index.html` → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сцена откроется по адресу `https://<логин>.github.io/iridescence-3d/`.

Альтернатива — Vercel: Add New → Project → импорт того же репозитория, Framework Preset «Other», Deploy.

**Параметры адреса:** `?hud=0` — без телеметрии; `?frame=3&frames=12` — статичный кадр под углом 90°; `?transparent=1` — прозрачный фон.

**Как подключить к Tilda Free:**

1. **Кнопка-ссылка** с «Открывать в новом окне» — работает гарантированно.
2. **GIF** `iridescence_turntable.gif` элементом Image — уже стоит в ZB01.
3. **Видео.** Запишите сцену (Win+Alt+R в Xbox Game Bar, 15 секунд), загрузите на YouTube как «Доступ по ссылке» и вставьте элементом Video в Zero Block.
4. **Iframe — только если HTML-элемент Zero Block доступен на вашем аккаунте.** Источники расходятся, поэтому проверьте сами: Add element → HTML. Вставьте код, опубликуйте страницу и откройте её. Если сцена видна — оставляйте, если нет — вариант 1.

```html
<iframe src="https://<логин>.github.io/iridescence-3d/?hud=1"
        title="Iridescence — условная 3D-реконструкция"
        style="width:100%;height:100%;border:0;border-radius:16px"
        loading="lazy" allow="fullscreen"></iframe>
```

**Пересборка кадров** (если поменяли сцену): `python media/3d/tools/frame_server.py --port 8791`, затем откройте `http://127.0.0.1:8791/iridescence-viewer/index.html?frame=0&frames=12&format=jpeg` и выполните в консоли браузера цикл из docstring скрипта — кадры сохранятся в `media/3d/turntable/`.
