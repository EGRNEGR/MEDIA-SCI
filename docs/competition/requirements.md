## Подтверждено официальными документами

### Задание по кейсу (D2, лист «Инструкция»)

- Актуализировать статью «Виртуальная одежда» **только по 18 выданным источникам**. Набор подготовлен 26.10.2026.
- Исходный текст — статья РУВИКИ: https://ru.ruwiki.ru/wiki/Виртуальная_одежда
- Обработать все 18 ссылок: для каждой заполнить статус, итог и ID строк. Если страница недоступна — зафиксировать проблему, а не объявлять материал нерелевантным.
- **Для доказательства использовать только выданные источники.**
- Одна строка = одно утверждение из одного источника. ID строки уникален (`R001…`), ID факта общий для подтверждений одного факта (`F001…`).
- Решение LLM: «Да» / «Нет» / «Требует проверки» с обоснованием, действием, разделом, точной цитатой-якорем из статьи и предлагаемым текстом. Для нового раздела указывается место добавления.
- Доказательство: ID источника и короткая точная цитата.
- Противоречия: в обеих связанных строках указываются встречные ID, расхождение и что проверить. При нехватке данных — «Требует проверки», спорный факт в статью не вносится.
- Итерации: при новом подтверждении или опровержении обновляется общий факт, в «Истории пересмотра» записывается «прежнее решение → новое, причина и источник». Дублирующие вставки не создаются.
- Столбцы A:N — итог модели, O:P — ручная проверка. Вывод LLM сохраняется, исправления человека фиксируются отдельно. Статья обновляется вручную.
- **Сдача по кейсу:** заполненная книга, HTML с обновлённой статьёй и мультимедиа, промпты и порядок их применения. В итоговой статье сохраняются ссылки на доказательства.
- Пустая дата публикации означает «не установлена». Дата события не заменяет дату публикации. Нормы по числу правок нет: важны обоснованность и точность. Не каждый источник обязан дать вставку.

### Формат сдачи (D1)

- Все материалы и результаты работы с нейросетями объединяются в единый интерактивный формат — **лонгрид или лендинг на платформе Tilda**.
- Задания, которые не вписываются в лонгрид, описываются в презентации.
- К финальному дедлайну должны быть загружены: лонгрид (лендинг), презентация и документ с описанием генерации.

### Защита (D1)

- **Первая защита — перед жюри, с презентацией:** 7 минут на выступление, затем вопросы. Нужно показать актуальность, логику работы, критический анализ, аспекты этики и фактчекинга, этапы и фактуру генерации, проблемы и решения.
- **Вторая защита — перед всеми участниками:** выходят 7 лучших команд; показывается сам проект без презентации, 5 минут; оценка — зрительское голосование.

### Рекомендации к презентации (D1, с. 2–3)

1. Показать наполнение, логику и структуру проекта; объяснить выбор формата.
2. Раскрыть работу с ИИ и фактчекинг: какие нейросети и для чего, как проверялись факты и по каким источникам.
3. Осветить этику и авторское право: откуда референсы, музыка, данные, есть ли ссылки на источники.
4. Провести честный критический анализ: что удалось, что нет, что бы улучшили, почему принимались решения.
5. Использовать визуал: фрагменты продукта, схемы, инфографику.
6. Говорить просто, без нерасшифрованных терминов.
7. Подготовиться к вопросам жюри.
