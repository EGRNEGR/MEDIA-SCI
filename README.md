# MEDIA-SCI — проект команды на хакатоне SCI Media AI

Командный репозиторий мультимедийного проекта по направлению «Научная коммуникация».

**Задание.** Актуализировать статью РУВИКИ [«Виртуальная одежда»](https://ru.ruwiki.ru/wiki/Виртуальная_одежда) по 18 источникам, выданным организаторами, и собрать на её основе мультимедийный лонгрид (лендинг). Название проекта командой пока не утверждено, поэтому здесь используется рабочее название по имени репозитория.

**Сроки (по документу организаторов «Формат сдачи проектов»).** 13 ноября: 08:00 — промежуточный дедлайн, 11:00 — финальный дедлайн. Подробности и расхождения между источниками требований — в [`docs/competition/requirements.md`](docs/competition/requirements.md).

## Структура

| Каталог | Назначение |
|---|---|
| `docs/competition/` | Требования хакатона, зафиксированные по документам организаторов |
| `docs/workflow/` | Роли в команде и редакционные стандарты |
| `source_materials/` | Исходные материалы организаторов и сведения о них |
| `research/` | Рабочие исследовательские материалы: выписки из источников, заметки |
| `factcheck/` | Результаты фактчекинга (ведутся в ветке `FactsCheck`) |
| `content/` | Тексты проекта: актуализированная статья, сценарии, подписи |
| `media/` | Изображения, видео, аудио, инфографика и сведения об их происхождении |
| `ai/` | Журнал работы с нейросетями: модели, промпты, порядок применения |
| `deliverables/` | То, что сдаётся организаторам: книга Excel, HTML, презентация, документ о генерации |

## Ветки

- `main` — общая командная ветка.
- `FactsCheck` — рабочая ветка фактчекинга. Результаты проверки попадают в `main` только после решения команды.

## Правила

1. Секреты, токены и ключи API в репозиторий не попадают.
2. Репозиторий публичный: полные копии чужих статей, изображений и других охраняемых материалов сюда не выкладываются — только ссылки и короткие цитаты с указанием источника.
3. Каждое фактическое утверждение проекта должно иметь источник из выданного набора. Подробности — в [`docs/workflow/editorial_standards.md`](docs/workflow/editorial_standards.md).
