# media

Изображения, видео, аудио, инфографика и другие мультимедийные элементы проекта.

## Правила

- Для каждого файла записывается происхождение: кто создал, каким инструментом (включая модель ИИ и промпт), на основе каких исходников, на каких условиях можно использовать.
- Сгенерированные материалы помечаются как созданные ИИ и в файле сведений, и в подписи на лендинге.
- Чужие изображения, музыка и видео добавляются только при наличии понятной лицензии или разрешения; ссылка на условия сохраняется.
- Числа и подписи на инфографике проходят ту же проверку, что и текст.
- Тяжёлые исходники (сырые видео, проектные файлы) в Git не добавляются — в репозитории хранится ссылка на место их размещения.
