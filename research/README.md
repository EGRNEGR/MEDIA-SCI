# research

Рабочие исследовательские материалы: выписки из источников, заметки, сопоставления, вспомогательные скрипты.

## Правила

- Выписка из источника содержит URL, дату обращения, способ получения текста и дословные цитаты.
- Полные копии чужих страниц хранятся только локально в `research/source_snapshots/`. Этот каталог исключён из Git: репозиторий публичный, а тексты источников охраняются авторским правом.
- Скрипты для пересчёта чисел сохраняются рядом с результатом, чтобы расчёт можно было повторить.
- Вывод нейросети помечается как вывод нейросети и не выдаётся за цитату источника.
