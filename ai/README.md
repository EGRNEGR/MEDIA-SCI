# ai

Журнал работы с нейросетями. Из него собирается обязательный документ с описанием генерации и ответ на требование задания сдать «промпты и порядок их применения».

## Что записывать

Для каждого применения нейросети:

1. Дата и участник.
2. Модель и сервис (точное название и версия, если известна).
3. Задача.
4. Промпт и входные материалы.
5. Что получено.
6. Что проверил человек и что исправил.
7. Выявленные ошибки и ограничения модели.

## Правила

- Записи делаются по ходу работы, а не восстанавливаются перед сдачей.
- Ключи API и токены в промпты и журналы не попадают.
- Если результат модели отброшен, это тоже записывается: неудачи нужны для критического анализа на защите.
